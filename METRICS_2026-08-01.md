# The controllability battery and scalar — how everything is computed

**Dated 2026-07-16; amended 2026-07-17** (projection channel default; scalar link is
`linear`-clip against per-measure `D_REF`, `phi` legacy), **2026-07-23** (**Suppress
and Layer targeting folded back INTO S** — the scalar is now a **seven-measure**
composite; `D_REF[suppress]` 1.0→3.0, `D_REF[layer_targeting]`=5.0 added), **2026-07-24**
(`D_REF[engage]` 8→16.4 and `D_REF[coverage]` 1.5→4.11, recalibrated on the 25-model
roster so neither axis saturates), and **2026-08-01** (this doc reconciled to the
seven-measure scalar). Single source of truth;
supersedes the earlier `SCORES.md` + `SCALAR.md` (both written for the retired
two-channel design and now deleted).
Everything below is read from the code, not from those docs:
`scripts/score_data.py` (readouts) → `scripts/compute_scores.py` (measures) →
`scripts/aggregate_scalar.py` (scalar) / `scripts/scalar_ci.py` (joint CI).
No model is loaded anywhere; all of it reads stored run artifacts.

## 1. The experiment and the readout

For each **(concept, sentence)** pair the model transcribes a fixed sentence while
following an instruction about a concept ("think about X", "don't think about X",
"think about X at intensity 3/4", "think about X only at the end", …). The
residual stream is recorded token-by-token at the analysis depths.

- **Data.** 10 concepts × 50 sentences = **500 units**; 20 analysis layers, at the
  originally-requested depth fractions **5 %…100 %** in steps of 5 %. Fractions
  resolve to each model's own layer count (`_layer_for_fraction`), so a depth means
  the same thing across models.
- **Concept vector ĉ.** Baseline-subtracted activation of "Tell me about X", per
  layer, unit-normalized.
- **Baseline.** The `no_instruction` condition ("just write the sentence"), read
  out the same way. Every score compares an instructed condition against it.

**Three channels** are computed and emitted (`score_data.unit_layer_readouts`):

| channel | definition | role |
|---|---|---|
| **`proj`** | per-token `cos × raw ‖r‖` = ⟨r, ĉ⟩ | **the paper channel** (default) |
| `cos` | cosine(residual, ĉ) — direction | legacy / appendix |
| `relnorm` | ‖r‖ ÷ trial's content-token mean norm — magnitude | legacy / appendix |

`proj` combines the other two. All three are written to
`results/SCORES_<model>.json`; the channel set is elected **downstream** at collapse
time (§5).

**Units — read this before quoting any d′.** Wherever a score divides by an SD it
is the **across-sentence SD of the baseline** (per concept). Generation is
deterministic — there is no trial noise — so σ is *content variability*. "d′ = 6"
means 6 × the sentence-to-sentence spread, **not** 6σ of measurement precision.

**Fixed depths.** Engage/Suppress/Dial sweep all layers and pick a peak. Coverage
and the targeting measures read at one fixed depth per channel:

| view | cos | relnorm | **proj** |
|---|---|---|---|
| POS / Coverage (`F_POS`) | 0.90 | 0.75 | **0.90** |
| Targeting (`F_LOC`) | 1.00 | 0.70 | **0.90** |

The proj depths were set empirically on the focal model (gemma3_27b) via
`scripts/proj_peak_depths.py`. Note `PROJ_F_LOC = 0.90 ≠ COS_F_LOC = 1.00`: on cos
the targeting contrast peaks at the final layer, on proj it peaks at 90 % and falls
off after.

## 2. The ten emitted measures

**Seven** feed the scalar; three are computed and emitted but **excluded by design**.

| # | measure | prompts vs | native score | in S? |
|---|---|---|---|---|
| 1 | Engage | `think_about` vs `no_instruction` | d′ | ✅ |
| 2 | Suppress | `dont_think_about` vs `no_instruction` | d′ (signed) | ✅ (captures a failure mode — see below) |
| 3 | Dial Rank | `think_intensity_{1..4}_of_4` | Spearman ρ ∈ [−1,1] | ✅ |
| 4 | Dial Resolution | same ramp | d′ from AUROC | ✅ |
| 5 | Dial Resolution (deep-pool) | same ramp | d′ from AUROC | ❌ secondary |
| 6 | Temporal control | `loc_beginning`, `persist_once`, `loc_end` vs `think_about` | SD-unit contrast | ✅ |
| 7 | Token group | `loc_punctuation`, `loc_adjectives` vs `think_about` | SD-unit contrast | ❌ |
| 8 | Coverage | `think_about` vs `no_instruction`, split by POS | min-POS d′ | ✅ |
| 9 | Layer targeting | `think_at_layer` (separate `--lt-run`) | demeaned diagonal | ✅ (designed null — see below) |
| 10 | Onset/offset error | `persist_after_fourth` (onset), `persist_first_half` (offset) | edge-timing error (↓) | ❌ |

Higher is better for all nine. The seven that feed S are #1–4, 6, 8, 9; the three
excluded are #5 (deep-pool resolution, a robustness check), #7 (token group) and
#10 (onset/offset error).

### 1. Engage
Per concept, per layer: `d′ = (mean_s think − mean_s baseline) / SD_s(baseline)`.
Average over the 10 concepts → one value per layer → take the **peak layer**
(`argmax`). Reported **signed**. A `wrong` companion records the most-wrong-way
layer.
**Drawback:** *peak-inside-replicate* — every bootstrap replicate re-picks its own
best layer, so the point estimate is mildly optimistic and the interval
upper-skewed. Also the single most saturated input to S (§6).

### 2. Suppress — *in S (folded back 2026-07-23)*
Identical machinery, instructed direction **down** (`sign = −1`): the peak *downward*
shift of `dont_think_about` vs `no_instruction`. Positive = compliance; **negative =
even the best layer moved the wrong way** (a rebound — "don't think of X" makes you
represent X).
**Why it's in S:** models essentially *cannot* suppress on command — `no_instruction`
is already the concept's resting floor, so there is little to push *below*, and the
main thing that moves is the white-bear **rebound**. That failure is a genuine fact
about controllability, so it belongs *in* the score rather than hidden as a
"diagnostic". Most models sit at d′ ≈ 0 → p ≈ 0.5 (a uniform attenuation that doesn't
reorder), and any genuine wrong-way rebound maps to p < 0.5 and legitimately drags S
down. `D_REF[suppress]` was raised **1.0 → 3.0** on 2026-07-23 so the lone
below-baseline outlier (Gemma 4 31B, d′ ≈ 1.45, wide CI) no longer saturates to full
credit above the honest ≈ 0.5 suppressors, and the geometric mean keeps that outlier
from rescuing a model that fails elsewhere. (Suppress was briefly *excluded*
2026-07-17 → 07-23 as a rebound diagnostic; folding it back makes S report the
suppression failure explicitly.) The `wrong-way` companion still records the strongest
rebound layer. A *proper* suppression task would suppress from an **elevated** baseline
(e.g. "think about X … now stop") — that needs new runs and is deferred.

### 3. Dial Rank
Per unit, per layer: **signed Spearman ρ** of the readout against intensity level
(needs ≥3 finite levels of 4). Mean over units; peak layer **L\*** = `argmax` of the
mean-unit rank. Range [−1, 1].
**Drawback:** rank-only — measures **order, not magnitude** (a big but jumbled
response scores low; a tiny but perfectly ordered one scores high). Only 4 points
per unit, smoothed by averaging over 500 units.

### 4. Dial Resolution
For each of the 3 **adjacent** pairs (1-2, 2-3, 3-4): win = 1 if the higher setting
read higher, 0.5 tie, 0 otherwise. Pool 3 pairs × units **at L\*** — the *same*
layer Dial Rank reports — → an **AUROC** → `d′ = √2·Φ⁻¹(AUROC)` (AUROC clamped to
[1e-6, 1−1e-6]). Reading both dial measures at L\* stops them from silently
contradicting each other when the dial is depth-localized.
**Drawback:** ignores the easy 1-vs-4 endpoint on purpose; a dial that only resolves
at one layer scores high here but low on the deep-pool variant (#5).

### 5. Dial Resolution (deep-pool)
Same, but pooled over the **deep band** (layers with `L/n_layers ≥ 0.5`) instead of
L\*. Emitted as a conservative depth-robustness check; **not** in S.

### 6. Temporal control
Told to think about X at the **beginning / middle / end**. Split the sentence's
tokens into *inside* the target third and *outside*; take
`(G_in/σ_on − G_out/σ_off)` of the concept signal (Δ vs baseline), then **subtract
the same contrast for the generic `think_about` prompt** — this removes the
concept's natural spatial footprint and isolates the location command itself.
σ_on/σ_off are the across-sentence SDs of the *baseline* series' in/out means, per
concept. Mean over units per task; group score = **mean of the three tasks**. Read
at a fixed depth, so no peak-picking bias.
**Drawbacks:** (a) **dominated by `end`** — the end task is far larger than begin
or mid, so this is effectively an end-targeting score; (b) **`mid` is a proxy** —
`persist_once` is a *temporal* "think once" prompt reinterpreted as a middle-third
*span*, the weakest task, negative on some models; (c) its SD-unit → AUROC link in
S is a **convention, not an identity** (§5).

### 7. Token group — *excluded from S*
Identical machinery to #6, but the target is a grammatical token group
(`loc_punctuation` → PUNCT, `loc_adjectives` → ADJ); score = mean of the two.
**Why excluded:** negative for essentially every model — the concept lands *away*
from the commanded tokens. It measures **avoidance, not graded competence**, and
would pull every model down near-equally: low information for a capability index.

### 8. Coverage
`think_about` vs `no_instruction` with the readout split by the 9 UPOS categories
(NOUN, VERB, DET, PUNCT, ADP, PRON, ADJ, ADV, CCONJ) at the fixed POS depth. Engage
**d′ per category**, then report the **minimum** across categories (the
weakest-covered one) plus its name — a worst-link breadth test.
**Drawbacks:** *min-inside-replicate* → mildly **pessimistic** (mirror of Engage's
optimism). Computed on **cos and proj only**: relnorm is deliberately excluded
because the magnitude engage effect is *bipolar* across POS (norm rises on content
words, falls on function words), so a "minimum" there would report a structural
magnitude reallocation, not a coverage gap.

### 9. Layer targeting — *in S (folded back 2026-07-23)*
From the **separate layer-targeting run** (`--lt-run`), with the target layer swept
over that run's own `prompt_layers`, baselined against the main run. Build
Δ[target T, readout L] and take
`D[u,l] = (Δ[T=l, L=l] − mean_T Δ[T, L=l]) / σ(l)` — the **diagonal** (response at
the layer you targeted) minus the **column mean** (that layer's average response
across all targets) — averaged over units. Because it is demeaned across targets it
measures **selectivity**, not overall response.
**Why it's in S:** a **designed null** — ≈ 0 for every model, because depth is not
addressable by a text instruction. Folded into S (2026-07-23) as an honest failure
axis: since every model scores ≈ 0, its `p ≈ 0.5` for all, so it is a **uniform drag
that does not reorder** models — but it keeps S from over-crediting "control" on an
axis where no model can actually act. It shares Temporal control's standardized-contrast
scale (`D_REF = 5.0`). It remains a useful negative control: the method finds
spatial/temporal targeting where it exists and correctly reports ≈ 0 here.

### 10. Onset/offset error — *excluded from S*
Told to **start** thinking about X after the 4th token (`persist_after_fourth`, an
onset gate) or **stop** after the first half (`persist_first_half`, an offset gate),
how far off is X's actual on/off edge? Per (sentence, concept) the per-token signal
(cond − baseline) is binned into **10 position bins**; averaging over units gives a
mean profile whose **half-max crossing** (first rise = onset, last fall = offset)
is the detected edge. Score = mean `|detected − requested|` in fractional position
over the two gates — bounded to **[0, 1]** (both positions are sentence fractions);
0 = perfect timing, 1 = maximally mistimed. **Lower = better.** Read at each
channel's targeting depth (cos 1.00, relnorm 0.70, **proj 0.90**). *(Folded back
into the live scorer 2026-07-17 with a proj channel added; the fold also fixed a
latent length-mismatch bug in the archived version.)*

**Word-based supersession (2026-07-22).** The requested onset above is the **4th
token** (`4/(n−1)`), but the prompt says "after the fourth **word**." Because token
strings are `tokenizer.decode()`d, a word boundary is a plain leading space on every
tokenizer — and on ones that split words into sub-tokens (GPT-OSS, Mistral) the
4th-word boundary lands a token or two past the 4th token. `scripts/onset_offset_word.py`
recomputes the onset gate against the actual 4th-word boundary (requested onset =
mean fractional position of the **5th-word-start** token) and writes
`ONSET_OFFSET_WORD_<model>.json`; the temporal figures source this. Across the panel
the word boundary is ≈`0.05` later in fractional position than the 4th token, so every
onset error shifts down by that constant. The **original SCORES value is left frozen**
(prior numbers still cite it). Mechanically this is an *exact constant shift* of the
onset edge — `req` enters `_persistence_edges` only as `error = detected − req`, so
detection, bootstrap, and the offset gate (`persist_first_half`, req 0.5) are
unchanged; the script reuses `_persistence_edges` verbatim and asserts its replicated
unit set reproduces the original token-`req`. Conditions are unchanged.
**Why excluded:** the sole **↓-is-better** measure, and it has **no natural chance
baseline** — so the scalar's `Φ(·/√2)` link (higher = better, 0.5 = chance) fits
neither its direction nor its scale. Also coarse (10 bins → ~0.1 resolution) with
**per-edge CI only** and no aggregate CI (the aggregate is a mean of absolute errors
across two different-condition edges, bootstrapped independently; and the 10-bin
half-max crossing quantizes the detected edge, making any bootstrap interval lumpy).

## 3. Confidence intervals

All CIs are a **two-way cluster bootstrap**, B = 2000, seed 0: each replicate
resamples **both** the 50 sentences and the 10 concepts with replacement and
recomputes the whole score. **CI = the 2.5 / 97.5 percentiles.** Two frozen kernels:

- **`dprime_stats`** — Engage, Suppress, Coverage. Sentence multiplicities `W` and
  concept multiplicities `Mc`; the peak (Engage/Suppress) or min (Coverage) is
  **re-taken inside every replicate**.
- **`twoway`** — Dial, Temporal control, Token group, Layer targeting. Unit-level
  weighted means with `w = Ws[:, sentence] * Wc[:, concept]`.

---

## 4. The scalar S — the joint CI

The per-measure CIs in `SCORES_<model>.json` are each drawn from their **own
independent** resample, so they **must never be combined component-wise** into an
interval for S — that would ignore the covariance between measures.
`scripts/scalar_ci.py` instead:

1. draws **one** canonical sentence-multiplicity matrix and **one** concept-
   multiplicity matrix over the union (sentence × concept) universe;
2. **projects** them onto each measure's own axes — so replicate *b* is the *same*
   resample in every measure (this is what makes it a *joint* two-way bootstrap);
3. recomputes all components on that shared resample with the same frozen kernels,
   aggregates to S exactly as below, and takes the 2.5 / 97.5 percentiles of the
   resulting S distribution.

The point estimate is computed from the observed statistics and is validated to
equal `aggregate_scalar.py`'s.

## 5. How S is computed

**Kept: seven measures** — engage, suppress, dial_rank, dial_resolution,
temporal_control, coverage, layer_targeting (each weight 1/7). Suppress and layer
targeting were folded back in 2026-07-23 (§2, §9): they measure axes on which models
demonstrably *fail*, so S reports those failures rather than hiding them, and the
conjunctive (geometric) mean stops one strong axis from masking them.

**Step 1 — score → probability p, where 0.5 = chance.** A fixed link (no
panel-dependent fitting — this is what keeps S *absolute*: a model's S never changes
when another model joins or leaves the panel). Two links are selectable via
`--link`; **`linear` is the default**, `phi` is the legacy AUROC link kept for
comparison.

**`linear` (default) — linear-clip against a per-measure ceiling `D_REF`:**

$$p = \operatorname{clip}\!\Big(0.5 + \frac{\text{score}}{2\,D_{\text{ref}}},\ 0,\ 1\Big)$$

Linear and fully discriminating from chance (score 0 → p 0.5) up to `D_REF` (→ p 1),
with a **deliberate ceiling** above it; a negative score → p < 0.5. Dial Rank keeps
`p = (ρ+1)/2` under both links (already bounded/linear). This replaced the AUROC link
because Φ saturates by d′≈4, so a strong axis like Engage compressed to p≈1 and
stopped discriminating — leaving the ranking to whichever axes sat near chance.

`D_REF` = the score meaning **"essentially perfect control"** for that axis. It is a
*definition* of perfect, not a fit; a bounded [0,1] score of an unbounded d′ **must**
have such a ceiling somewhere — the choice is only where. **Values (initially chosen
2026-07-17 on the 8-model panel, projection channel; suppress + layer_targeting added
2026-07-23; engage & coverage recalibrated 2026-07-24 on the 25-model roster — full
provenance in `aggregate_scalar.py`. The metric's calibration constants: REVISIT and
re-run all models if the panel grows or the notion of "perfect" per axis changes):**

| measure | `D_REF` | rationale |
|---|---|---|
| Engage | **16.4** | "magnitude" reading (a bigger commanded push counts); set ×1.02 above the roster-max d′ (16.06) so the strongest model lands at p≈0.99 not pinned at 1.0 *(was 8; raised 2026-07-24)* |
| Temporal control | **5** | same, dominated by the huge "end" task; capped below its max |
| Dial Resolution | **3** | d′≈3 = 0.98 AUROC on the hardest (adjacent-step) test |
| Coverage | **4.11** | a worst-case min over POS; set ×1.02 above roster-max (4.03) so it stops saturating *(was 1.5; raised 2026-07-24)* |
| Suppress | **3.0** | structurally tiny headroom; raised from 1.0 *(2026-07-23)* so the lone below-baseline outlier stays off the ceiling above the honest ≈0.5 suppressors |
| Layer targeting | **5.0** | shares Temporal control's standardized-contrast scale; every model ≈0 → p≈0.5 *(added 2026-07-23)* |
| Dial Rank | *(n/a)* | uses `(ρ+1)/2` |

**`phi` (legacy AUROC link):** `p = Φ(score/√2)` for the d′/contrast measures (= the
AUROC of the effect; for Temporal control it's the same convention, not a literal
AUROC), `(ρ+1)/2` for Dial Rank, the stored AUROC for Dial Resolution. Retained via
`--link phi` for the appendix and for reproducing the earlier scalar.

**Step 2 — weights: measure-equal.** Each of the **N present** measures carries
`1/N`; within a measure that weight splits evenly across its **present channels**.

- **Projection (default):** every measure is single-channel → **1/7 each** (all 7
  kept measures present).
- *Legacy* (`--channels legacy`): two-channel measures split their 1/N across cos +
  relnorm; coverage is cos-only.

Missing channels/measures drop out and the rest renormalize, preserving the
measure-equal intent.

**Step 3 — aggregate conjunctively, rescale at the end.**

```
G = exp( Σ_i w_i · ln p_i )        # weighted GEOMETRIC mean of the RAW p
S = clip( 2G − 1, 0, 1 )
```

Geometric (not arithmetic) makes S **conjunctive**: it rewards *broad* control and
is dragged down by any single weak axis, so a model cannot buy a high score by
acing one capability and failing others. The mean is taken over the **raw** p, so
an at-chance component enters as 0.5 and merely *attenuates* the product — had p
been pre-rescaled to 0 it would **annihilate** G entirely the moment one axis (e.g.
structurally-small Suppress) sat at chance.

All components at chance → G = 0.5 → **S = 0**. All perfect → G = 1 → **S = 1**.

**Channel & link selection.** `aggregate_scalar.py` and `scalar_ci.py` both take
`--channels {projection,legacy,all}` (default **projection**) and
`--link {linear,phi}` (default **linear**). Both are recorded in the emitted
`SCALAR.json` / `SCALAR_CI_<model>.json` (`channel_set`, `link`, `d_ref`).

## 6. Negatives and flooring — what actually gets clipped

**No individual measure is floored.** This is deliberate:

- Engage / Suppress are **signed, no floor** — a negative Suppress is a real
  "even the best layer still moves the wrong way" (a rebound), not masked as 0.
  (An older design floored these at 0 and hid rebounds; that floor was removed.)
- Dial Rank spans [−1, 1]; Dial Resolution goes negative when AUROC < 0.5; Coverage's
  min-POS d′, Temporal control, Token group and Layer targeting can all be negative.

**Negatives survive into the collapse.** A negative score maps through its link to
**p < 0.5** and legitimately drags G down. It is *not* clipped up to 0.5 and *not*
discarded.

**Clips (under the default `linear` link):**

1. **Per-measure ceiling** — `p = clip(0.5 + score/(2·D_REF), 0, 1)` caps each axis at
   p = 1 for score ≥ `D_REF` (and at 0 for score ≤ −`D_REF`). This is the deliberate
   "essentially perfect" ceiling; two current models clip Engage. (`phi` instead
   saturates *smoothly* — no hard clip, but compressed to ≈1 from d′≈4 up.)
2. `p` is clamped to **[1e-6, 1−1e-6]** — purely to keep `ln p` finite.
3. **`S = clip(2G − 1, 0, 1)`** — the final floor. A **net-below-chance model floors
   at S = 0**: if the weighted geometric mean of its p's is ≤ 0.5, everything below
   collapses to 0 and the *degree* of below-chance-ness is not distinguishable.

**In the current panel nothing floors at S = 0.** The lowest models (the two GPT-OSS
runs) sit around S ≈ 0.06–0.08 under the seven-measure linear scalar, above the floor
— the final clip is currently inert, but would bite for any model that goes
net-negative.

## 7. Drawbacks worth knowing before quoting S

1. **Link saturation — fixed in the default, still present in `phi`.** Any bounded
   link of an unbounded d′ must flatten somewhere. The **legacy `phi`** link
   (`p = Φ(d′/√2)`) flattens *early* — above **d′ ≈ 4** it is 1.000 to three
   decimals (Engage 5.55 and 10.55 both → 1.000), so strong axes (Engage, Temporal
   control) contributed nothing and the ranking fell to the near-chance axes
   (Suppress, Coverage). The **default `linear`** link moves the ceiling out to each
   axis's `D_REF` and stays linear below it, so Engage/Temporal discriminate again in
   their meaningful range. It still has a **hard ceiling** at `D_REF` (any score ≥
   `D_REF` ties at p = 1) — that is deliberate ("essentially perfect"), and revisable
   by raising `D_REF` if a stronger cohort warrants it.
2. **Suppress and Layer targeting are (back) in S** (2026-07-23, §2/§9). Both were
   briefly excluded (2026-07-17 → 07-23); folding them back makes S report the two axes
   where models most clearly *fail* — suppression and depth targeting — rather than
   hiding them. Both sit near chance for essentially every model (`p ≈ 0.5`), so they
   act as a near-uniform attenuation that barely reorders the panel, while the geometric
   mean stops a lone strong axis from papering over them. `D_REF[suppress]` = 3.0 keeps
   the one below-baseline outlier (Gemma 4 31B, d′ ≈ 1.45, wide CI) off the ceiling.
   (Under the retired `phi` scalar with suppress *excluded*, the spread was 0.74 → 0.84;
   the current linear seven-measure scalar is the shipped definition.)
3. **Peak/min-inside-replicate.** Engage & Suppress select a best layer (mildly
   optimistic, upper-skewed CI); Coverage selects the worst POS (mildly
   pessimistic). Dial and the targeting measures are fixed/pooled and unbiased here.
4. **σ is content variability, not noise** (deterministic generation) — see §1.
5. **Absolute ⇒ the link constants are the whole ballgame.** S is only as meaningful
   as the pre-registered links; changing them changes every model. They are fixed on
   purpose and must not be tuned per panel.
6. **One condition can dominate a group.** Temporal control is carried by `end`;
   always look at the per-task breakdown before reading it.
7. **Projection alone loses the old cross-check.** The retired two-channel design
   used relnorm as the sanity check on cos (a small baseline σ can inflate cos-d′).
   Collapsing to `proj` removes that internal check — cos/relnorm are still emitted
   to the JSON, but verifying a suspicious proj d′ against them is now a manual step.

## 8. How to run

Normally you don't run these by hand: **`scripts/run.sh <config>`** runs the
experiment and then `scripts/postprocess.py` chains all of the below (score →
PROFILES → CI → per-model figures → cross-model superplot). The individual steps:

```bash
# per model: measure JSON (all 3 channels) + depth-profile curves, from stored artifacts.
# --lt-run is optional: without it, layer_targeting is emitted null (a main-only run scores).
python scripts/compute_scores.py --main-run <M> [--lt-run <L>] \
    --json results/SCORES_<model>.json --profiles-json results/PROFILES_<model>.json

# collapse across all models (point estimates). Defaults: --channels projection --link linear.
python scripts/aggregate_scalar.py --json results/SCALAR.json          # add --link phi for the legacy AUROC scalar

# joint two-way bootstrap CI for one model (needs the run dir, not just the JSON)
python scripts/scalar_ci.py --main-run <M> --json results/SCALAR_CI_<model>.json

# cross-model comparison figures (reads only the JSONs; never recomputes)
python scripts/superplot.py     # -> results/model_comparison.png + null_measures_model_comparison.png
```

The paper figures (`engage_suppress_a3i.py`, `think_intensity_a3i.py`,
`scalar_a3i.py`, …) live in the sibling **`figure_scripts/`** directory and read these
JSONs via `--data-root`/`$AC_DATA` (see `figure_scripts/a3i_paths.py`).

Each model has **two** runs: a **main** run (`no_instruction_cache.pkl`; all
condition sets) and a **layer-targeting** run (the `_lt`-tagged `think_at_layer`
sweep). Layer targeting needs the latter as `--lt-run`; S does not.

## 9. Not computed (retired)

Two centroid-precision companions are retired and **no longer computed** (the
archive `scripts/No_longer_computed_SCORES.py` was deleted 2026-07-17):
**Temporal control (CoM)** and **Token group (CoM)** — signal-weighted centroid
distance to target, tiny everywhere (~±0.1 / ±0.05 of the sentence) and adding
little the kept in/out-contrast rows don't already carry.

*(Onset/offset error was the third retired measure; as of 2026-07-17 it is folded
back into the live scorer as measure #10 above — computed on all three channels,
excluded from S.)*
